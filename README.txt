MAFYKE-PELIMAAILMA – JULKAISUPOHJA

1. Avaa index.html selaimessa. Se on sivuston etusivu.
2. Pelit ovat games-kansion alla aineittain.
3. Uuden pelin lisääminen:
   - kopioi HTML-peli oikeaan aineen kansioon
   - lisää index.html-tiedostoon linkki peliin samalla tavalla kuin Suoran piirtäminen -linkki
4. Kun kokonaisuus toimii omalla koneella, koko mafyke-pelimaailma-kansio voidaan viedä GitHubiin ja julkaista Cloudflare Pagesilla/GitHub Pagesilla.

Nykyinen esimerkkipeli:
games/matematiikka/suoran-piirtaminen.html
